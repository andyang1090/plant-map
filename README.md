# 厂图 · 厂区机柜管理系统

打开 **index.html** 即可使用，无需安装依赖、无需部署服务器。双击本地文件即可。

启动时只加载项目门户（轻量）；打开项目后才会加载 `dist/` 下的编辑器脚本。请保持 `index.html` 与 `dist/` 在同一目录结构中。

- 总平图绘制车间，双击车间进入内部图纸。
- 选择工具后在画布上拖动绘制车间、机房、机柜、备注或轴线。
- 选择对象可以拖动位置、拖动右下角调整大小，在属性面板编辑名称、尺寸和备注。
- 车间支持横轴、纵轴及统一/单独隐藏。
- 无限平移画布，支持负坐标；拖动空白区域、空格拖动或中键拖动平移。
- 滚轮以鼠标位置缩放，工具栏「适应」恢复总览。网格自动调整密度，可独立隐藏。
- 车间内部轴线点击放置、预览位置、自动连续编号、自动对齐附近图形边缘，支持 Alt 临时关闭对齐。
- 「轴网」面板按数量、间距和起点批量生成横纵轴线，自动跳过重合位置；轴线随画布延伸。
- 机柜等对象可连续点击放置或拖动绘制，Esc / V 返回选择，Delete 删除。
- 支持撤销、JSON 导入导出。拖动只更新当前对象，输入属性时保持面板焦点。
- 图纸自动保存在当前浏览器 localStorage。初次加载包含演示数据。

总平图不设轴线。每个车间的轴线、编号、间距与显隐设置独立保存。

使用「多边形车间」逐点绘制不规则轮廓，点击起点闭合，或双击 / Enter 完成。进入车间会显示相同轮廓作为参考。使用「墙体」在总平图或车间绘制折线墙，Shift 正交约束，自动吸附已有墙体端点，支持墙厚、移动、复制与备注。

墙体画完自动进入选择模式。拖动墙线移动整面墙，拖动圆点修改端点和转角，点击中点方块添加转角；右侧「墙体节点」支持坐标输入和删除节点。至少保留两个节点，拖动节点时 Shift 保持正交，Esc 取消当前拖动，Ctrl+Z 撤销。

多选：使用「框选」工具拖动框住多个对象（也能从机房内部开始），或在选择模式的空白处拖动。只选择完整框住的对象。Ctrl 点击增减选择，Ctrl 框选追加，Ctrl+A 全选当前图纸可见对象，Esc 取消选择。拖动任一已选对象整体移动，Delete 批量删除，Ctrl+Z 撤销。框选完成后自动回到选择模式；平移使用空格、中键或「平移」工具。

吸附默认开启，可以在工具栏关闭，设置随图纸保存。工具栏「文字」调整全局图纸字号；选中单个或多个对象后，可在右侧调整所选对象字号，或恢复跟随全局。字号以屏幕像素显示，缩放后文字仍清晰可读。

车间内的轮廓参考可在工具栏隐藏、删除或恢复，仅影响当前车间内部的参考线，不修改总平图上的车间轮廓。状态随图纸保存，支持撤销。

同时选中横轴与纵轴时，交点显示「横轴名/纵轴名」组合文字，如 A/1、B/23；隐藏或取消选择后不显示。顶部统计与标题合并在同一行，为地图留出更多空间。

当前版本为浏览器本地版本，尚未接入多人共享数据库、登录和权限管理。重要数据请定期导出 JSON 备份。

## 楼层

进入车间后，点击标题旁的楼层标签一键切换（当前层高亮，也支持左右方向键），或打开「管理楼层」新增、保存名称、切换、删除楼层。每个车间至少保留一层。原有图纸自动保留在默认的 1F，新增楼层为空白图纸；每层独立保存机房、机柜、墙体、轴线、备注以及轴线/轮廓参考显隐。总平图统计所有楼层，复制车间会复制其全部楼层。楼层操作支持撤销，JSON 导入导出包含楼层数据，旧版备份仍可导入。

文字缩放：工具栏可选择「文字固定大小」（缩放地图时屏幕字号不变）或「文字随图缩放」（地图放大时文字同步放大）。右侧可为单个或多个对象指定模式，或跟随全局设置。

数据迁移与楼层复制/删除校验：`node checks/floor-data.test.cjs`。

图纸坐标采用 1 px = 1 m（5 px = 5 m），屏幕缩放不改变实际距离。工具栏「轴距」默认 15 m，可直接修改并随图纸保存。第一根轴线自由定位，后续同向轴线以鼠标最近的可见同向轴线为参照，按设定间距定位，可向两侧连续添加；Alt 临时自由定位。批量轴网的横纵间距也默认采用此设置。



系统名称与厂区名称可直接点击编辑，Enter 保存。Ctrl+S 保存当前图纸视图（位置、缩放、网格、吸附、文字设置与轮廓/轴线状态）；总平图和各车间楼层分别保存，刷新或重新进入时恢复。
机柜与机房统一为机房，以五角星显示；旧机柜的名称、状态、型号和备注保留。新机房默认以小型星标放置。
开启吸附后，绘制与移动支持吸附墙体端点、转角及图形节点，命中时显示橙色圆点；Alt 临时关闭吸附。
绘制横轴/纵轴时显示轴距浮动输入框，可直接输入数字并按 Enter 确认；也支持在画布上直接敲数字唤起输入。机房不再显示运行状态，支持颜色选择，新机房点击放置默认大小为 4 m × 4 m，已有机房尺寸保留。

轴距修复：确认的轴距优先于节点吸附，新增轴线严格按输入间距放置，以鼠标最近的可见同向轴线为参照，鼠标位置决定放在哪一侧。输入轴距后按 Enter 生效。新机房默认 4 m × 4 m，宽高可在属性面板自行修改，已有尺寸不变。


支持在 A 轴上方或已有轴线之间插入：预览显示参照轴线名称和间距。隐藏轴线、垂直方向轴线不参与最近参照判断。若目标位置已有轴线，请调小轴距或按 Alt 自由定位。

机房尺寸调节点大小随机房短边按18%同比例缩放，不再使用固定大小方块。双击机房星标可直接编辑显示名称，Enter保存，Esc取消，点击其他位置也可保存。

「机房默认尺寸」可设置之后新建机房的默认宽高，初始4m×4m，设置随图纸保存，已有对象不变。
Ctrl+C复制选中的一个或多个对象，Ctrl+V粘贴到当前图纸，支持跨楼层、保留相对位置和属性、连续粘贴及撤销；复制车间包含其全部楼层。输入框内仍按普通文字复制粘贴处理。顶部也提供复制、粘贴按钮。
轴距输入支持两位小数，最小0.01m，输入有效数字后立即生效，无须Enter。浮动输入框与工具栏输入框同步；Enter返回画布。空值/非正数不会覆盖上一次有效轴距。
Esc统一取消当前绘制、框选、拖动或机房文字编辑，关闭设置窗口并返回选择工具；拖动中的几何修改回滚。开启吸附后可吸附当前楼层可见横纵轴线的交点，不需要先选中轴线；隐藏轴线不参与。右侧逐根隐藏轴线的管理列表已移除，工具栏轴线总开关保留。
墙体起点与后续节点统一吸附：优先附近的图形节点、轴线交点，也可吸附到单根可见轴线上。吸附在网格取整之后应用，保留两位小数；关闭吸附或按Alt时自由定位。
新建墙体默认厚度为1m，绘制预览同步采用该厚度；已有墙体厚度不变，可在属性面板修改。
墙体节点拖动修复：先做网格/正交处理，最后应用精确节点或轴线交点吸附，防止吸附坐标被再次取整。命中时实际墙点与提示圆点保持一致，节点坐标显示保留两位小数。
Delete删除修复：点击画布对象时将焦点移回画布，Delete统一直接删除单个或多个选中对象，支持撤销；文字输入框及设置窗口内不触发对象删除。
Ctrl+L切换正交模式，也可使用工具栏正交开关，状态随图纸保存。正交模式约束墙体/多边形绘制、墙体节点及对象拖动，Shift仍可临时开启正交。选中对象后方向键每次微移0.1m，Shift+方向键每次移动1m，支持多选与撤销；长按同一方向键按一次连续操作撤销。输入框和楼层标签内方向键保留编辑/切换行为。
F3开启/关闭吸附模式（含轴距输入框聚焦时），工具栏勾选状态同步，设置自动保存；长按不重复切换，Alt仍可临时关闭吸附。

画布前进/后退：鼠标侧键后退/前进可返回当前会话访问过的总平图、车间、楼层，恢复离开时的缩放与位置；顶部也提供前后按钮，浏览器原生前进/后退同样有效。
Alt临时关闭吸附修复：绕过鼠标坐标的网格取整，保留小数自由定位，按住时工具栏显示临时关闭状态。
单选任意轴线，在属性面板设置「本层横轴统一长度」或「本层纵轴统一长度」，同层同方向轴线共用起点与长度并自动对齐；横轴相对纵轴跨度居中，纵轴相对横轴跨度居中。默认长度均为 600 m，可修改统一起点。

## WebMap 项目主页

启动后进入 Office 风格的项目主页，可新建、搜索、重命名项目，也可双击项目行的空白位置打开。主页左侧「导入 JSON」会将系统导出的图纸导入为独立项目，以文件名命名，同名时自动编号，不覆盖已有项目。支持最大 5 MB 的系统 JSON 图纸。

旧版图纸自动保留为「默认项目」。项目之间的图纸、楼层、视图和设置独立保存。删除项目会移入回收站，可以恢复。数据保存在当前浏览器中，建议定期导出备份。

鼠标前进、后退支持主页与画布之间导航，也支持车间、楼层之间导航。

## 免部署多文件版（按需加载）

直接双击本目录的 `index.html` 打开项目门户，不需要服务器、安装依赖或联网。

- `index.html`：启动页 / 项目门户（仅加载 `project-storage.js`、`portal.js`）
- `dist/`：编辑器资源；打开项目后按需加载
- 返回「项目主页」会卸载编辑器并回到轻量门户

请固定使用同一浏览器、同一路径打开文件。图纸保存在浏览器本地；换电脑或移动文件前建议导出 JSON 备份。
